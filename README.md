# student-score-predictor
This project predicts student exam scores based on study hours using Machine Learning.

languages Used:
- Python
- Pandas
- Scikit-learn
- Matplotlib

Machine Learning Model:
Linear Regression

How it works:
The model learns the relationship between study hours and exam scores and predicts future scores.

Example:
Study Hours → Predicted Score
6 hours → 76.777 marks
